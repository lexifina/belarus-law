# Статья 47
Сведения, используемые для разработки проектной документации
1. Для разработки проектной документации используются предпроектная (предынвестиционная) документация (при ее наличии), данные градостроительного кадастра, республиканского фонда проектной документации, республиканского банка данных объектов-аналогов на строительство объектов, фондов материалов изыскательских работ в соответствии с разрешительной документацией на строительство.
2. Перечень данных градостроительного кадастра, необходимых для разработки проектной документации, и порядок их предоставления определяются Министерством архитектуры и строительства.
