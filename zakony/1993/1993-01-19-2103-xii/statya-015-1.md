# Статья 15-1
Комиссия по преобразованию предприятия в открытое акционерное общество
Комиссия по преобразованию предприятия в открытое акционерное общество (в дальнейшем - комиссия по преобразованию) создается на предприятии для разработки проекта создания открытого акционерного общества в процессе приватизации государственной собственности. Порядок разработки проектов создания открытых акционерных обществ определяется Мингосимуществом.
Комиссия по преобразованию организует проведение инвентаризации, выявляет дебиторов и кредиторов предприятия, принимает меры для расчетов с ними, готовит предложения об условиях использования объектов социальной инфраструктуры, находящихся на балансе предприятия, определяет стоимость государственного имущества и величину уставного фонда создаваемого открытого акционерного общества.
Комиссия по преобразованию несет ответственность за полноту инвентаризации, правильность оценки стоимости имущества и определения величины уставного фонда открытого акционерного общества и вправе на договорной основе привлекать экспертов, аудиторов и специализированные организации по отдельным направлениям работ.
