# Статья 18
Классификация полезных ископаемых
1. Полезные ископаемые исходя из их физических и технологических свойств подразделяются на:
1.1. рудные;
1.2. нерудные;
1.3. горючие;
1.4. подземные воды.
2. Полезные ископаемые исходя из их экономического значения подразделяются на:
2.1. стратегические полезные ископаемые;
2.2. общераспространенные полезные ископаемые;
2.3. полезные ископаемые ограниченного распространения;
2.4. подземные воды.
