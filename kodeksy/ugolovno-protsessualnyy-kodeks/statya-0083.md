# Статья 83
Отвод секретаря судебного заседания
1. Основания для отвода, изложенные в части первой статьи 77 настоящего Кодекса, относятся к секретарю судебного заседания. Предыдущее его участие в производстве по данному уголовному делу в качестве секретаря судебного заседания не является основанием для отвода.
2. Вопрос об отводе секретаря судебного заседания разрешает суд, рассматривающий уголовное дело.
