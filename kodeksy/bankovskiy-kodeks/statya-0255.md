# Статья 255
Виды аккредитива
Аккредитивы выполняют расчетную функцию и (или) функцию обеспечения исполнения обязательств.
При выполнении расчетной функции и функции обеспечения исполнения обязательств аккредитив может быть подтвержденным, неподтвержденным, покрытым, непокрытым, возобновляемым (револьверным), невозобновляемым, со специальной оговоркой, переводным, компенсационным, микроаккредитивом.
Аккредитив, выполняющий только функцию обеспечения исполнения обязательств, является резервным.
