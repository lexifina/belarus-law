# Статья 65
Исчисление пенсий при переводе с одной пенсии на другую
При переводе с одной пенсии на другую среднемесячный заработок определяется на общих основаниях, установленных настоящим Законом. Пенсия по новому основанию может также исчисляться (по желанию пенсионера) из того заработка, из которого определялась ранее назначенная пенсия.
