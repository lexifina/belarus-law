# Статья 291
Секретарь судебного заседания
1. Секретарь судебного заседания проверяет явку лиц, вызванных в судебное заседание, по поручению председательствующего осуществляет другие процессуальные действия, предусмотренные настоящим Кодексом.
2. Секретарь судебного заседания ведет протокол судебного заседания. Он обязан полно и правильно излагать в протоколе действия и решения суда, а равно действия участников судебного разбирательства, имевшие место в ходе заседания.
3. В случае разногласия с председательствующим по поводу содержания протокола секретарь вправе приложить к протоколу свои замечания, которые рассматриваются в порядке, предусмотренном статьями 310 и 311 настоящего Кодекса.
4. Секретарю судебного заседания может быть заявлен отвод, который разрешается по правилам, установленным статьей 83 настоящего Кодекса. Предыдущее участие в качестве секретаря судебного заседания не является основанием для отвода.
