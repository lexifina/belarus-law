# Статья 50-9
Судебные коллегии Апелляционного экономического суда
Составы судебных коллегий Апелляционного экономического суда утверждаются председателем Апелляционного экономического суда по согласованию с Верховным Судом Республики Беларусь из числа судей Апелляционного экономического суда для специализированного рассмотрения дел.
Руководство работой судебных коллегий осуществляют заместители председателя суда, входящие в состав соответствующих коллегий.
В судебных коллегиях Апелляционного экономического суда председателем Апелляционного экономического суда формируются составы суда для коллегиального рассмотрения дел.
Председатель Апелляционного экономического суда в необходимых случаях вправе привлекать судей, входящих в состав одной из судебных коллегий, к рассмотрению дел, отнесенных к компетенции другой судебной коллегии.
