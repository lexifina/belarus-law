# Статья 120
Основания для прекращения дисциплинарного производства
Дисциплинарное производство прекращается:
при отсутствии оснований для привлечения судьи к дисциплинарной ответственности;
при пропуске сроков привлечения к дисциплинарной ответственности, предусмотренных статьей 113 настоящего Кодекса;
при нецелесообразности наложения дисциплинарного взыскания в случае, если есть возможность ограничиться рассмотрением дисциплинарного производства на заседании соответствующей квалификационной коллегии судей.
