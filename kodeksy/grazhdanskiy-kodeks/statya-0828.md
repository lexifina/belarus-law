# Статья 828
Страховщики
1. Страховщики - коммерческие организации, созданные для осуществления страховой деятельности и имеющие лицензии на осуществление страховой деятельности.
Для отдельных видов страхования актами Президента Республики Беларусь может быть предусмотрен иной состав страховщиков.
2. Требования, которым должны отвечать страховщики, и порядок лицензирования их деятельности определяются законодательством.
