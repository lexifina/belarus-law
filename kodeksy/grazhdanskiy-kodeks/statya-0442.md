# Статья 442
Срок годности
1. Законодательством или другими обязательными правилами может быть определен срок, по истечении которого товар считается не пригодным для использования по назначению (срок годности).
2. Товары, на которые установлен срок годности, продавец обязан передать покупателю с таким расчетом, чтобы он мог быть использован по назначению до истечения срока годности.
