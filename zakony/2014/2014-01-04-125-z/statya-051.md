# Статья 51
Спортивная дисквалификация
1. Спортсмены, тренеры, судьи по спорту, иные специалисты, а также животные, участвующие в спортивных мероприятиях, могут быть подвергнуты спортивной дисквалификации за допинг в спорте в порядке, установленном Положением об антидопинговых правилах Республики Беларусь, по решению Национального антидопингового агентства, компетентных международных спортивных организаций.
Спортсмены, тренеры, судьи по спорту, иные специалисты могут быть подвергнуты спортивной дисквалификации за нарушение правил спортивных соревнований по виду спорта, положений о проведении (регламентов проведения) спортивных соревнований, решений федераций (союзов, ассоциаций) по виду (видам) спорта, международных спортивных организаций в порядке, установленном правилами спортивных соревнований по виду спорта, по решению федераций (союзов, ассоциаций) по виду (видам) спорта, компетентных международных спортивных организаций.
2. Материальное обеспечение спортсменов, тренеров, иных специалистов, осуществляемое за счет средств республиканского и (или) местных бюджетов, на период спортивной дисквалификации может быть прекращено или ограничено в соответствии с законодательством.
