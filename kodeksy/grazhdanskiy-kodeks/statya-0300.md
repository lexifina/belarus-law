# Статья 300
Очередность погашения требований по денежному обязательству
Сумма произведенного платежа, не достаточная для исполнения денежного обязательства полностью, при отсутствии иного соглашения погашает прежде всего издержки кредитора по получению исполнения, затем - проценты и неустойку, а в оставшейся части - основную сумму долга.
