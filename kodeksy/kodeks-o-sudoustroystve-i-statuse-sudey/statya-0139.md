# Статья 139
Гарантии, связанные с исполнением обязанностей народных заседателей
Увольнение народных заседателей с основной работы по инициативе нанимателя, за исключением случаев совершения народным заседателем виновных действий (бездействия), допускается при соблюдении общего порядка, предусмотренного законодательством о труде, и только с согласия должностного лица (органа), утвердившего списки народных заседателей.
