# Статья 350
Прекращение трудового договора с работающими по совместительству
Помимо оснований, предусмотренных настоящим Кодексом и другими актами законодательства, трудовой договор с работающим по совместительству может быть прекращен в случае приема на работу работника, для которого эта работа будет являться основной.
