# Статья 54
Дополнительная ответственность участников общества с дополнительной ответственностью
При недостаточности имущества общества участники отвечают по его обязательствам в пределах, определенных уставом пропорционально их долям в имуществе общества. Договором между участниками общества с дополнительной ответственностью может быть предусмотрен иной порядок распределения дополнительной ответственности.
При недостаточности имущества одного или нескольких участников общества для обеспечения причитающейся с них доли дополнительной ответственности ответственность по недостающей сумме несут остальные участники общества пропорционально их долям в имуществе этого общества.
