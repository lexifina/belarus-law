# Статья 4
Требования по охране труда
Требования по охране труда - нормативные предписания, направленные на сохранение жизни, здоровья и работоспособности работающих в процессе трудовой деятельности, содержащиеся в нормативных правовых актах, в том числе технических нормативных правовых актах.
Требования по охране труда обязательны для исполнения работодателями и работающими.
При отсутствии в нормативных правовых актах, в том числе технических нормативных правовых актах, требований по охране труда работодатели принимают необходимые меры, обеспечивающие сохранение жизни, здоровья и работоспособности работающих в процессе трудовой деятельности.
