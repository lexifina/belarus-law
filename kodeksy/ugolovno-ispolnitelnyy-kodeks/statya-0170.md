# Статья 170
Передача материалов для постановки имущества, конфискованного по приговору суда, на учет в комиссии по работе с имуществом, обращенным в доход государства
Материалы для постановки на учет имущества, конфискованного по приговору суда, в соответствии с законодательными актами Республики Беларусь передаются в комиссии по работе с имуществом, обращенным в доход государства.
