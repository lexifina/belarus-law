# Статья 313
Индексация присужденных денежных сумм
1. По заявлению взыскателя, поданному в пределах срока, установленного законодательством об исполнительном производстве для предъявления исполнительного документа к исполнению, суд, рассмотревший дело, может произвести индексацию присужденных судом в пользу взыскателя денежных сумм на день исполнения судебного постановления, за исключением денежных сумм, присужденных экономическим судом.
2. Если иное не предусмотрено актами законодательства, для индексации используется официальная статистическая информация об индексе потребительских цен.
