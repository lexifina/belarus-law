# Статья 699
Внесение изменений в проектную документацию
1. Заказчик вправе требовать внесения в проектную документацию изменений, не связанных с дополнительными расходами для подрядчика.
2. Изменения проектной документации, требующие дополнительных расходов для подрядчика, осуществляются за счет заказчика на основе согласованной сторонами дополнительной сметы.
3. Подрядчик вправе требовать в соответствии со статьей 420 настоящего Кодекса пересмотра сметы, если по не зависящим от него причинам стоимость работ превысила смету не менее чем на десять процентов.
4. Подрядчик вправе требовать возмещения разумных расходов, которые понесены им в связи с установлением и устранением дефектов в проектной документации.
