# Статья 45
Социальная защита пенсионеров пожарной службы
За работниками пожарной службы, уволенными со службы по достижении установленного возраста, по болезни, по ограниченному состоянию здоровья, по сокращению штатов при наличии у них оснований для назначения пенсии по линии Министерства внутренних дел Республики Беларусь, сохраняется право пользования льготами, предусмотренными для работников пожарной службы.
