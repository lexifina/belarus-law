# Статья 6.4
Объяснения лица, в отношении которого ведется административный процесс
1. Объяснения лица, в отношении которого ведется административный процесс, - сведения об обстоятельствах, имеющих значение для принятия решения по делу об административном правонарушении, сообщенные этим лицом при опросе, в том числе при составлении протокола об административном правонарушении, а также при производстве иных процессуальных действий с его участием.
2. Лицо, в отношении которого ведется административный процесс, вправе давать объяснения по поводу административного правонарушения, иных известных ему обстоятельств, имеющих значение для принятия решения по делу об административном правонарушении, и имеющихся в деле доказательств.
