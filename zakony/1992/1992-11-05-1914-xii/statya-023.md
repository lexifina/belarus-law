# Статья 23
Сроки военной службы
Для военнослужащих устанавливаются следующие сроки военной службы:
проходящим срочную военную службу:
не имеющим высшего образования, - 18 месяцев;
имеющим высшее образование, - 12 месяцев;
проходящим военную службу по контракту на должностях:
солдат, матросов, сержантов и старшин, - 2 года;
прапорщиков и мичманов, - 5 лет;
офицеров, - 5 лет по первому контракту после окончания военно-учебного заведения;
для офицеров, призванных или принятых в добровольном порядке на военную службу из запаса, - 2 года.
Военнослужащим срочной службы, перешедшим на военную службу по контракту, при досрочном расторжении контракта (кроме случаев, предусмотренных в статье 26: по болезни; по сокращению штатов - при невозможности использования на службе в связи с сокращением штатов или организационными мероприятиями; по семейному положению и другим обстоятельствам, препятствующим исполнению обязанностей военной службы, - по просьбе военнослужащего) время прохождения службы по контракту в срок срочной военной службы не засчитывается.
Для лиц, проходящих военную службу по контракту, военная служба может быть продлена по окончании срока службы по вновь заключенному контракту на срок не менее 3 лет каждый раз до достижения предельного возраста состояния на военной службе.
Срок службы для военнослужащих срочной службы, отбывавших наказание в дисциплинарных частях, определяется в соответствии с действующим законодательством.
