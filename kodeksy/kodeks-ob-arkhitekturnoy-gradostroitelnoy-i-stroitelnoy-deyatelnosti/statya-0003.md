# Статья 3
Классы сложности объектов
1. Объекты классифицируются по пяти классам сложности. Высший класс сложности объекта - первый класс, низший класс сложности объекта - пятый класс.
2. Отнесение объекта к конкретному классу сложности осуществляется заказчиком, застройщиком совместно с разработчиком проектной документации в соответствии с классификацией объектов, установленной строительными нормами. Класс сложности объекта указывается в проектной документации.
