# Статья 54
Предоставление земельных участков для народных художественных ремесел
Земельные участки для народных художественных ремесел предоставляются в пожизненное наследуемое владение гражданам Республики Беларусь или аренду гражданам, зарегистрированным по месту жительства на территории Республики Беларусь, по решению районных исполнительных комитетов.
