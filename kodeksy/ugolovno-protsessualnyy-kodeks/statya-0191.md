# Статья 191
Окончание производства предварительного расследования
Производство предварительного расследования заканчивается вынесением постановления о передаче уголовного дела прокурору для направления в суд, постановления о прекращении производства по уголовному делу либо постановления о передаче дела прокурору для направления в суд для решения вопроса о применении принудительных мер безопасности и лечения.
