# Статья 226
Доверительное управление денежными средствами по согласованию
При доверительном управлении денежными средствами по согласованию доверительный управляющий осуществляет действия с денежными средствами вверителя при условии обязательного предварительного согласования с вверителем каждого осуществляемого им действия.
