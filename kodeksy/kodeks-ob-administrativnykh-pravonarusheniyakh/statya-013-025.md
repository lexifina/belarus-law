# Статья 13.25
Нарушение требований при осуществлении деятельности по оценке стоимости объектов гражданских прав
Осуществление деятельности по оценке стоимости объектов гражданских прав с нарушением требований, предусмотренных законодательными актами об оценочной деятельности, -
влечет наложение штрафа в размере до тридцати базовых величин.
