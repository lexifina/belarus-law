# Статья 28
Объекты налогообложения
1. Объектами налогообложения признаются обстоятельства, с наличием которых у плательщика настоящий Кодекс, другие законы Республики Беларусь и (или) акты Президента Республики Беларусь либо решения местных Советов депутатов (в отношении местных налогов и сборов) связывают возникновение налогового обязательства.
2. Каждый налог, сбор (пошлина) имеет самостоятельный объект налогообложения.
3. Один и тот же объект может облагаться определенным налогом, сбором (пошлиной) у одного плательщика только один раз за соответствующий налоговый период.
