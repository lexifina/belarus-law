# Статья 74
Требования к документам, являющимся основанием для государственной регистрации сделки с недвижимым имуществом
1. Документы, являющиеся основанием для государственной регистрации сделки с недвижимым имуществом, из которых явствует волеизъявление гражданина, должны быть нотариально удостоверены либо удостоверены регистратором.
2. Документы, являющиеся основанием для государственной регистрации сделки с недвижимым имуществом, из которых явствует волеизъявление юридического лица, должны быть подписаны его руководителем либо другим лицом, уполномоченным на это учредительным документом, или иным уполномоченным лицом в соответствии с законодательством и могут быть нотариально удостоверены либо удостоверены регистратором.
Документы, являющиеся основанием для государственной регистрации сделки с недвижимым имуществом, из которых явствует волеизъявление индивидуального предпринимателя, должны быть им подписаны и могут быть нотариально удостоверены либо удостоверены регистратором.
