# Статья 42-1
Члены окружных избирательных комиссий по выборам депутатов Палаты представителей с правом совещательного голоса
Политическая партия, выдвинувшая кандидата в депутаты Палаты представителей, вправе направить в окружную избирательную комиссию члена комиссии с правом совещательного голоса со дня регистрации кандидата в депутаты Палаты представителей, выдвинутого этой политической партией.
Срок полномочий члена окружной избирательной комиссии с правом совещательного голоса начинается со дня получения окружной избирательной комиссией решения руководящего органа политической партии о направлении члена окружной избирательной комиссии с правом совещательного голоса.
Члену окружной избирательной комиссии с правом совещательного голоса выдается удостоверение, форма которого устанавливается Центральной комиссией.
Членами окружной избирательной комиссии с правом совещательного голоса не могут быть кандидаты в депутаты Палаты представителей, их доверенные лица, представители по финансовым вопросам.
Члены окружной избирательной комиссии с правом совещательного голоса обязаны соблюдать Конституцию Республики Беларусь, выполнять требования настоящего Кодекса и иных актов законодательства Республики Беларусь о выборах, не совершать действий, дискредитирующих окружную избирательную комиссию или препятствующих ее работе.
Член окружной избирательной комиссии с правом совещательного голоса вправе:
вносить в повестку дня заседаний окружной избирательной комиссии предложения по вопросам, входящим в ее компетенцию, и требовать проведения голосования по ним;
выступать на заседаниях окружной избирательной комиссии;
задавать участникам заседания окружной избирательной комиссии вопросы в соответствии с повесткой дня и получать на них ответы;
знакомиться с документами и материалами, которые рассматриваются на заседании окружной избирательной комиссии.
Член окружной избирательной комиссии с правом совещательного голоса не вправе:
участвовать в проводимых окружной избирательной комиссией проверках, в голосовании при принятии комиссией решений;
давать разъяснения и указания, делать сообщения от имени окружной избирательной комиссии.
Полномочия члена окружной избирательной комиссии с правом совещательного голоса досрочно прекращаются:
по его письменному заявлению;
по решению окружной избирательной комиссии при выбытии из избирательного округа кандидата в депутаты Палаты представителей, выдвинутого политической партией;
по решению руководящего органа политической партии об отзыве направленного им члена окружной избирательной комиссии;
в случае прекращения гражданства Республики Беларусь.
Полномочия члена окружной избирательной комиссии с правом совещательного голоса могут быть досрочно прекращены по решению окружной избирательной комиссии при совершении им действий, дискредитирующих окружную избирательную комиссию или препятствующих ее работе.
В случае досрочного прекращения полномочий члена окружной избирательной комиссии с правом совещательного голоса окружная избирательная комиссия аннулирует выданное ему удостоверение.
Полномочия членов окружной избирательной комиссии с правом совещательного голоса прекращаются после установления окружной избирательной комиссией результатов выборов депутата Палаты представителей по избирательному округу.
