# Статья 257
Банк-посредник (расчетный центр)
Если платежное поручение исполняется через банк (банк-посредник, расчетный центр), не являющийся банком-отправителем либо банком-получателем, то соответственно к банку-посреднику (расчетному центру), получившему платежное поручение, применяются правила, установленные для банка-получателя, а к банку-посреднику (расчетному центру), отправившему платежное поручение, - правила, установленные для банка-отправителя.
