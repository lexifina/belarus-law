# Статья 67
Требования к документам, являющимся основанием для государственной регистрации сделки с недвижимым имуществом
1. Документы, являющиеся основанием для государственной регистрации сделки с недвижимым имуществом, из которых явствует волеизъявление гражданина, должны быть нотариально удостоверены либо удостоверены регистратором.
2. Документы, являющиеся основанием для государственной регистрации сделки с недвижимым имуществом, из которых явствует волеизъявление юридического лица, должны быть подписаны его руководителем либо другим лицом, уполномоченным на это учредительными документами, или иным уполномоченным лицом в соответствии с законодательством Республики Беларусь.
Документы, являющиеся основанием для государственной регистрации сделки с недвижимым имуществом, из которых явствует волеизъявление индивидуального предпринимателя, должны быть им подписаны и могут быть нотариально удостоверены либо удостоверены регистратором.
3. Документы, являющиеся основанием для государственной регистрации сделки с недвижимым имуществом, из которых явствует волеизъявление государственного органа, должны быть выполнены на бланке соответствующего государственного органа и подписаны его руководителем либо другим лицом, уполномоченным на это положением или иным нормативным правовым актом о данном государственном органе.
