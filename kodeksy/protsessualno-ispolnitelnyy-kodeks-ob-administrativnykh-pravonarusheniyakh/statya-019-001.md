# Статья 19.1
Органы, исполняющие административное взыскание в виде лишения права заниматься определенной деятельностью
1. Административное взыскание в виде лишения права заниматься деятельностью, связанной с управлением транспортными средствами, исполняется уполномоченными лицами органов внутренних дел.
2. Административное взыскание в виде лишения права заниматься деятельностью, связанной с управлением моторными маломерными судами, исполняется уполномоченными лицами Государственной инспекции по маломерным судам.
3. Административное взыскание в виде лишения права заниматься деятельностью, связанной с охотой, исполняется организациями Министерства лесного хозяйства.
4. Административное взыскание в виде лишения права заниматься видом деятельности, на осуществление которой требуется специальное разрешение (лицензия), приводится в исполнение должностным лицом органа, выдавшего специальное разрешение (лицензию).
