# Статья 280
Расчеты с использованием чеков
Чеком признается ценная бумага, содержащая ничем не обусловленное распоряжение чекодателя провести платеж указанной в нем суммы чекодержателю.
В качестве плательщика по чеку может быть указан только банк, где чекодатель имеет средства, которыми он вправе распоряжаться путем выставления чеков.
Отзыв чека до истечения срока для его предъявления не допускается.
Правила проведения безналичных расчетов посредством чеков устанавливаются Национальным банком.
