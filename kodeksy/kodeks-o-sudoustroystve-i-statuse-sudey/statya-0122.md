# Статья 122
Наложение дисциплинарного взыскания Президентом Республики Беларусь
Президентом Республики Беларусь при наличии оснований, предусмотренных настоящим Кодексом, может быть наложено любое дисциплинарное взыскание на любого судью без возбуждения дисциплинарного производства. При этом судья может давать объяснения по поводу совершенного им дисциплинарного проступка.
