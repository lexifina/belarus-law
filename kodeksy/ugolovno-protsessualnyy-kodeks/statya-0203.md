# Статья 203
Основания для проведения осмотра
Основанием для проведения осмотра места происшествия, трупа, местности, помещения, жилища и иного законного владения, предметов, документов и компьютерной информации является наличие достаточных данных полагать, что в ходе этих следственных действий могут быть обнаружены следы преступления и иные материальные объекты, выяснены другие обстоятельства, имеющие значение для уголовного дела.
