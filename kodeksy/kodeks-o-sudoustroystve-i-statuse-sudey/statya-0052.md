# Статья 52
Состав Верховного Суда Республики Беларусь
Верховный Суд Республики Беларусь состоит из судей Верховного Суда Республики Беларусь, в том числе Председателя Верховного Суда Республики Беларусь, первого заместителя и заместителей Председателя Верховного Суда Республики Беларусь. Количество заместителей Председателя Верховного Суда Республики Беларусь определяется Президиумом Всебелорусского народного собрания по представлению Председателя Верховного Суда Республики Беларусь.
Верховный Суд Республики Беларусь действует в составе:
Пленума Верховного Суда Республики Беларусь;
Президиума Верховного Суда Республики Беларусь;
судебной коллегии по гражданским делам Верховного Суда Республики Беларусь;
судебной коллегии по уголовным делам Верховного Суда Республики Беларусь;
судебной коллегии по экономическим делам Верховного Суда Республики Беларусь;
судебной коллегии по делам интеллектуальной собственности Верховного Суда Республики Беларусь.
При необходимости Президентом Республики Беларусь по представлению Председателя Верховного Суда Республики Беларусь в Верховном Суде Республики Беларусь могут образовываться иные судебные коллегии для специализированного рассмотрения дел.
Для рассмотрения в апелляционном порядке конкретных гражданских и уголовных дел, судебные постановления по которым вынесены Верховным Судом Республики Беларусь по первой инстанции, в Верховном Суде Республики Беларусь действует апелляционная инстанция Верховного Суда Республики Беларусь.
Количественный состав судей Верховного Суда Республики Беларусь устанавливается Президиумом Всебелорусского народного собрания по представлению Председателя Верховного Суда Республики Беларусь.
